# GUI 测试用例目录

每次 GUI 需求验证前，先在本目录新建或更新一个 Markdown 用例文件，再启动 GUI 执行检查。
这里记录“要测什么和怎么判定”，不保存临时 CDP 脚本、日志或截图。

## 命名

```text
YYYYMMDD-简短需求名.md
```

例如：

```text
20260803-settings-theme.md
```

## 模板

```markdown
# 需求名

## 用例

- 标准冒烟
  - 前置：dev GUI，固定端口或隔离目录
  - 操作：运行 `docs/cdp-testing.md` 第 3 节快速冒烟
  - 断言：标题、基础界面、输入区、CDP 标记、IPC bridge 正常
  - 证据：返回对象

- 主成功路径
  - 前置：
  - 操作：
  - 断言：
  - 证据：

- 关键边界或回归路径
  - 前置：
  - 操作：
  - 断言：
  - 证据：
```

## 取舍

- 用例要短，能指导执行即可。
- 只写本次需求相关路径，不把完整回归清单搬进来。
- 临时 `.js` 检查脚本仍放在 `.xhtest-*` 或其他临时位置，不提交到本目录。
